Relative path

Absolute path

Relative Path:

A relative path is a way to specify the location of a file or folder in relation to the current directory. Instead of starting from the root directory, it starts from the current working directory, making it flexible for referencing resources within a project.

Example:
./images/photo.jpg (refers to a file in the "images" folder in the current directory)

Absolute Path:

An absolute path is the full path that specifies the exact location of a file or folder, starting from the root directory. It provides the complete address, ensuring the resource can be located regardless of the current working directory.

Example:
C:/Users/Shreya/Documents/images/photo.jpg (Windows)
/home/shreya/documents/images/photo.jpg (Linux/Mac)
