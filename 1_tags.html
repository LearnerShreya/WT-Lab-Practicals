1. Heading Tag

The heading tags (<h1> to <h6>) are used to define headings in HTML. The <h1> tag represents the most important heading, and <h6> is the least important. Here's an example:

<h6>Leat Important Heading</h6>

OUTPUT:
Leat Important Heading

2. Paragraph Tag

The <p> tag is used to define a block of text or a paragraph in HTML. It automatically adds space around the text. Example:

<p>This is a paragraph.</p>

OUTPUT:

This is a paragraph.

3. Horizontal Rule Tag

The <hr> tag inserts a horizontal line across the page, often used to separate content sections. Example:

<hr>

OUTPUT:

4. Line Break Tag

The <br> tag is used to force a line break in text without starting a new paragraph. Example:

<br>

OUTPUT:

5. Preformatted Text Tag

The <pre> tag displays preformatted text, preserving all spaces, line breaks, and indentations as they appear in the source code. This is useful for showing code snippets or text that requires exact formatting. Example:

<pre>This is preformatted text.</pre>

OUTPUT: 
This is 
        preformatted text.
